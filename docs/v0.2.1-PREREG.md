# v0.2.1 release run: pre-registration (2026-10-18)

Written and committed before the run. v0.2.1 is v0.2.0 plus two things, nothing else:
- **S28:** a single HTTP 403 on a start-up `/me` request no longer signs the user out. The storefront sign-in check (`covers.rs`), the engine's `checkStorefront` (`player.js`) and library paging (`ui/library.rs`) retry a 403 with S20's backoff, at most 3 requests within the 10 s deadline. Only a 403 that persists signs the user out. This is the cause of `v020-counted-1`'s F4 failure (`docs/v0.2.0-RESULTS.md`).
- **A test-only fix:** `the_app_retries_a_failed_home_chart_only_while_home_is_the_route` now waits up to 5 s for the Home retry instead of a fixed 1 s window. In 6 full app-suite runs under load it passed 6 of 6, and it still fails when the retry ignores the route.

Versions: `crates/app` 0.2.1 and `crates/engine` 0.2.1. The engine change is additive (`player.js` behaviour, plus the exported `STOREFRONT_BACKOFF` and `STOREFRONT_DEADLINE` constants), so it is a patch bump.

The integration branch is `natevick/v0.2.1`.
