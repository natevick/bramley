# v0.4.1 release run: pre-registration (2026-10-19)

Written and committed before the run. v0.4.1 is v0.4.0 plus two things, nothing else:
- **S33, a volume slider** in the player bar, left of shuffle and repeat. It works before the first play: a volume set early is applied when the engine starts. It persists in `<config>/volume` (default 100), and status reports `volume`. Behaviour change: `bramley volume N` before a play now exits 0 instead of being refused. At the default volume of 100 the engine receives exactly the commands it did before.
- **A test-only fix:** the warm tests' Unix socket path exceeded the 108-character limit in longer worktree paths. They now use the repo root and a short tag.

Versions: `crates/app` 0.4.1. `crates/engine` is unchanged at 0.2.1, so there is no engine publish.

The integration branch is `natevick/v0.4.1`.
