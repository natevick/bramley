**The counted-2 regression.**
- Commit 17f9eb5 moved the desktop text-settings detection (`fastframe_text::detect()`) off the startup path.
- The app then called `ctx.set_fonts` a second time. egui compares the old and new FontDefinitions byte by byte, and that read every mapped fallback font file in full (NotoSansCJK alone is 18.6 MiB): about +20 MiB.
- Fixed in e17fc34 (skip when the detected rendering equals the applied one) and 52aed3b (set fonts only when the font tweak changes).
- Idle on Home: fixed 75.2 / 48.4 MiB PSS / USS, against v0.7.0's 74.4 / 47.6.

**counted-3 and counted-4 at the fixed commit.** Every check except R3 PASSed in both runs:
- R1 PSS 183.5 and 180.8 (v0.7.0: 182.2);
- R2 87.3 and 84.5;
- F1 every launch ≤ 213 ms;
- leak grep clean, both planted controls found, real state unchanged, pacing OK, and the ballast held.

R3 was voided both times by a host memory reclaim mid-soak (follow-up S52). Two consecutive VOIDs triggered Amendment 19's stop rule, and the decision went to Nate.
