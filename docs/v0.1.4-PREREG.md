# v0.1.4 release run: pre-registration (2026-10-16)

Written and committed before the run. v0.1.4 carries:
- shuffle and repeat through MusicKit, one-line now-playing text, and a plain "Signed in to Apple Music" footer (`natevick/player-controls`);
- an Artists section in search, a full-width results column, A–Z jump and type-to-jump on Artists and Albums, and recently played on the empty Search page (`natevick/browse-fixes`);
- the acceptance gate voiding a session that does not start with shuffle and repeat off (Amendment 16 of the acceptance gate).

The integration branch is `natevick/v0.1.4`. `crates/app` is 0.1.4 and `crates/engine` is 0.1.3, because `js/player.js` and `js/trace.js` changed.

## The run
`scripts/acceptance.sh v014-counted-1`, counted mode, from a clean tree, at the commit that last changed this file (`git log -1 --format=%H -- docs/v0.1.4-PREREG.md`).

## Pass
- The gate PASSes under `docs/acceptance.md` and `docs/s13-acceptance-PREREG.md` Amendments 4–15, plus Amendment 16. Amendment 16 is the shuffle and repeat VOID rule: a session whose guard record has a mode on is VOID, and a guard whose `modes` are missing, null or partly null is a FAIL.
- `realStateUnchanged` is true, and the leak grep is clean.

## Decision
- **PASS:** the branch merges to main, then Nate is asked about the v0.1.4 release and publishing `bramley-engine` 0.1.3.
- **FAIL:** nothing merges. Name the failing check.
- **VOID:** under the existing rules, re-run with the next name (`v014-counted-2`); don't judge it.

## Covers
The new recently-played grid on the empty Search page does not count toward Home's `texturesUploaded`.
- `texturesUploaded` reads `Grid::uploaded()`, the length of Home's `Grid.textures` (`crates/app/src/app.rs:279`, `crates/app/src/covers.rs:672,782-784`). The only write to that map is `crates/app/src/covers.rs:744`, in `Grid`'s own receive.
- The Search grid loads through `Search.recent_art`, its own `Art` with its own texture map (`crates/app/src/ui/search.rs:54,78,282`), and its fetches use a fresh `Tally` (`search.rs:356`). It does not touch `Grid`, `coversRequested` or `decodedInFlight`.
- It is asked for only on the Search route with an empty query (`crates/app/src/app.rs:590-594`), so the Home waits for `COVERS = 50` in `drive.py` and `gate.py` are unchanged.
