# v0.2.0 release run: pre-registration (2026-10-16)

Written and committed before the run. v0.2.0 carries everything in `docs/v0.1.4-PREREG.md`, because v0.1.4 was merged but never tagged:
- shuffle and repeat through MusicKit, one-line now-playing text, and a plain "Signed in to Apple Music" footer;
- an Artists section in search, a full-width results column, A–Z jump and type-to-jump on Artists and Albums, and recently played on the empty Search page;
- the acceptance gate voiding a session that does not start with shuffle and repeat off (Amendment 16).

It adds:
- version 0.2.0 for both `crates/app` (`bramley`) and `crates/engine` (`bramley-engine`). `Command::Repeat` and `Command::Shuffle` break downstream exhaustive matches on the engine's public `Command`, so the engine takes a minor bump while 0.x;
- `#[non_exhaustive]` on the engine's `Command`, `Queue`, `PlayState`, `PlayerError` and `EngineConfig`;
- the type-to-jump fix: the typed prefix and the item names are normalised the same way, so a name with a space or punctuation matches instead of the list paging to the bottom.

The integration branch is `natevick/v0.2.0`.

## The run
`scripts/acceptance.sh v020-counted-1`, counted mode, from a clean tree, at the commit that last changed this file (`git log -1 --format=%H -- docs/v0.2.0-PREREG.md`).

## Pass
- The gate PASSes under `docs/acceptance.md` and `docs/s13-acceptance-PREREG.md` Amendments 4–16.
- `realStateUnchanged` is true, and the leak grep is clean.

## Decision
- **PASS:** the branch merges to main. Then v0.2.0 is released and `bramley-engine` 0.2.0 is published; Nate approved both on 2026-10-16.
- **FAIL:** nothing merges. Name the failing check.
- **VOID:** under the existing rules, re-run with the next name (`v020-counted-2`); don't judge it.

## Did it run
The verdict must show:
- `commit` = the commit that last changed this file, and `dirty` false;
- mode counted;
- all 16 checks present;
- R3 carrying `seekLandingsS`, with one landing per R3 seek;
- every main session's guard record carrying `modes` equal to `{shuffleMode: off, repeatMode: off}`;
- `target/acceptance/v020-counted-1/bin/bramley --version` printing `bramley 0.2.0`. `build.json` records each binary's sha256 and size, not its version, and the gate does not read it. Check it by hand on the binary the run measured; `--version` needs no session, and the run's cleanup leaves `bin/` in place.
