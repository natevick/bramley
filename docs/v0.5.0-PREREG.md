# v0.5.0 release run: pre-registration (2026-10-20)

Written and committed before the run. v0.5.0 is v0.4.2 plus S35, small-window layouts, nothing else:
- **The five resize-QA breaks are fixed.**
  - The player bar never overlaps; volume folds into an icon with a popup below 800 px.
  - The queue docks only while content keeps 320 px, and otherwise overlays.
  - The detail header stacks.
  - The sidebar footer has its own panel.
  - The A–Z strip thins, and every letter stays reachable.
- **A compact tier below 640 px:** a ☰ drawer sidebar, a two-row player bar and a full-content queue sheet.
- **A minimum window of 360x480.**
- At 1280x800 the layout is pixel-identical to v0.4.2, except that the sidebar footer sits about 3 px lower. See `docs/s35-*` if present, and the QA findings in the session scratch.

Versions: `crates/app` 0.5.0, a minor bump for a feature. `crates/engine` is unchanged at 0.2.1, so there is no engine publish.

The integration branch is `natevick/v0.5.0`.
