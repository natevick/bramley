# v0.7.3 release run: pre-registration (2026-10-27)

Written and committed before any counted run. v0.7.3 is main (9505d4b) plus a version bump. Nate approved shipping on 2026-10-27 ("ship v0.7.3"); the gates are unchanged by that.

## What is in it (since v0.7.2)
- **Dock icon (macOS):** egui no longer paints its default icon over the Dock icon (`with_icon(IconData::default())`).
- **S54 parked windows:**
  - an AeroSpace-parked window (all but a sliver off every display) stops painting while it plays and keeps a 30 s wake path;
  - `windowParked` and `windowRect` join the status;
  - `schedule` now separates the Playing tick from the other tickers, which is the one Linux-visible change.
- **Icon:** the bow tie of LED meter bars replaces the apple (`packaging/icons`, `AppIcon.icns`).
- **Sign-in page:** the wait text reads "Apple Music sign-in".
- **Docs and packaging:** README rewrite, compliance scope, decisions, AUR README. No code.
- **Not changed:** `crates/engine`, `crates/core` and `crates/api`. `bramley-engine` stays 0.4.0 and nothing is published to crates.io.
- **Version:** `crates/app` 0.7.3 and `Cargo.lock`.

The release branch is `natevick/v0.7.3`.
